# NoSleep

켜 두는 동안 Windows가 유휴 절전 모드로 들어가지 않게 하는 아주 작은 트레이 앱입니다.

- 실행 파일 5KB, 설치 불필요
- 기능은 딱 하나: 실행 중에는 절전 안 함, 종료하면 원래대로
- 디스플레이는 평소 설정대로 꺼집니다 (컴퓨터만 깨어 있음)
- CPU 사용 거의 0 (타이머·폴링 없음)
- 실제 메모리 사용 약 5MB

## 리소스 사용량

이틀 연속 실행 후 측정한 값입니다 (Windows 11, RAM 32GB).

| 항목 | 값 | 설명 |
|---|---|---|
| 작업 관리자 표시 메모리 | 약 29MB | .NET·WinForms 등 다른 프로그램과 공유하는 시스템 라이브러리 포함 |
| **NoSleep 전용 메모리** | **약 5MB** | 이 앱만 단독으로 점유하는 실제 메모리 |
| CPU | 거의 0% | 시작 시 API 한 번 호출 후 대기만 함 |

장시간 실행해도 메모리가 늘어나지 않았습니다.

## 사용법

1. [Releases](../../releases)에서 `NoSleep.exe`를 받아 실행합니다.
2. 트레이에 초록색 동그라미 아이콘이 생기면 절전 방지 중입니다.
3. 아이콘을 우클릭하면 메뉴가 나옵니다.
   - **Windows 시작 시 실행**: 체크하면 로그인할 때 자동으로 켜집니다. 다시 누르면 해제.
   - **종료**: 절전 방지를 끄고 앱을 닫습니다.

> Windows 11은 새 트레이 아이콘을 작업표시줄의 `^` 숨김 영역에 넣습니다. 아이콘이 안 보이면 거기를 확인하세요.

자동 실행은 현재 사용자 레지스트리(`HKCU\...\Run`)에 등록되며, 작업 관리자 "시작 앱" 탭에서도 확인·해제할 수 있습니다.

## 삭제

설치형 프로그램이 아니라서 "프로그램 제거" 목록에는 없습니다. 아래 순서로 지우면 아무것도 남지 않습니다.

1. 트레이 아이콘 우클릭 → **Windows 시작 시 실행** 체크 해제
2. 우클릭 → **종료**
3. `NoSleep.exe` 파일 삭제

1번을 빼먹고 exe를 먼저 지웠다면, PowerShell에서 자동 실행 항목을 직접 지우세요.

```powershell
Remove-ItemProperty HKCU:\Software\Microsoft\Windows\CurrentVersion\Run -Name NoSleep
```

> 서명되지 않은 실행 파일이라 SmartScreen 경고가 뜰 수 있습니다. 걱정되면 아래처럼 소스를 직접 빌드하세요.

## 직접 빌드

Windows에 기본 포함된 .NET Framework 컴파일러를 사용합니다.

```bat
build.bat
```

## 작동 원리

시작할 때 Windows API를 한 번 호출합니다.

```csharp
SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED);
```

Windows는 입력이 없는 시간이 절전 설정값에 닿아도, "시스템 필요" 요청을 낸 프로그램이 있으면 절전하지 않습니다. 앱이 종료되면(강제 종료 포함) 요청은 자동으로 해제됩니다.

수동 절전, 전원 버튼, 노트북 덮개 닫기는 막지 않습니다.
